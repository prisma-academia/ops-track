# UI Enhancement Prompt (Preserve Existing Design)

You are a senior UI/UX designer and frontend engineer.

**Important:** Do **NOT** redesign the page. Preserve the existing layout, styling, colors, spacing, background, typography, card design, animations, and overall visual identity.

The current UI should remain exactly as it is. Only implement the following enhancements while maintaining the same design language.

## Required Changes

### 1. Reposition the Form Card

* Move the existing form card to the **right side** of the page.
* Do not modify the card's design, styling, spacing, shadows, or components.
* Keep the card width and appearance consistent with the current UI.

### 2. Add a Left Information Section

Create a professional content section on the **left side** that complements the form.

Include:

* A strong headline
* A short descriptive paragraph explaining the purpose of the application
* 3–5 feature highlights with simple icons
* Clean spacing and modern typography
* Vertically centered alignment with the form card

Example content sections:

* Fast & Secure
* Real-Time Processing
* Easy to Use
* Trusted by Businesses
* Modern Experience

The left section should feel like a premium SaaS landing page while matching the existing visual style.

---

### 3. Add a Professional Header

At the very top of the page, add a clean responsive header.

**Left**

* Company logo
* Company name (optional)

**Right**

* Dark/Light mode toggle
* Currency selector/switch

Requirements:

* Minimal
* Modern
* Responsive
* Consistent with the current UI
* Do not change the existing page background.

---

### 4. Add a Footer Area

At the bottom of the page, below the main content, add a clean footer containing:

* ⭐ Star rating
* Customer comments/reviews
* Small user profile avatars
* User name
* User role/title
* "Powered by [Company Name]"

Arrange everything neatly with balanced spacing and subtle styling.

Example:

★★★★★ 4.9/5

"Very fast and easy to use."

👤 John Doe
Senior Accountant

Powered by CompanyName

Keep the footer compact and elegant.

---

## Responsiveness

Desktop:

* Left informational section
* Right form card

Tablet:

* Maintain balanced spacing
* Stack gracefully if necessary

Mobile:

* Header remains at the top
* Information section appears before the form
* Footer stays at the bottom
* Preserve padding and spacing
* No overflow or layout shifts

---

## Design Rules

* Do NOT change the existing background.
* Do NOT change the existing form card.
* Do NOT change existing colors.
* Do NOT change typography unless needed for the new sections.
* Do NOT remove any existing components.
* Do NOT alter existing spacing except where required to fit the new layout.
* Match all border radius, shadows, hover effects, and animations with the current design.
* Maintain the current design system and visual consistency.

The final result should look like these additions were part of the original design, creating a polished, premium, enterprise-grade interface without altering the existing UI.
